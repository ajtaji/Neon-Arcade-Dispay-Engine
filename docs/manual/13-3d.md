# The 3D renderer

`Gl3D.pbi` draws 3D models into the engine's canvas: models read from glTF binary files, or triangles a program makes itself, lit by a fixed studio light, with skinning, animation clips and simple spring bones. It needs OpenGL 3.3, and checks for it. Include it after `GlUtilities.pbi`; it brings its five companion files.

## The pass

3D drawing happens inside a **pass** (`G3DPass`) on the canvas framebuffer. The setup, once:

1. `InitRetroCRT(W, H)` - the canvas framebuffer the pass draws into.
2. `GL_ContextCapture(@Context)` - the 3D module works only in the context it was set up in, and finds it through the current `GLWindowContext`.
3. `G3D_Init(@Pass)` - attaches a 24-bit depth buffer of the canvas's size to the canvas framebuffer and compiles the shader. It is refused if the canvas has no framebuffer, already has a depth buffer, or OpenGL is older than 3.3.

Each frame, with `Util_FBO` bound:

1. `G3D_Begin(@Pass)` - saves the OpenGL state it will change, turns blending and clipping off, turns the depth test on and clears the depth buffer. It is refused if the canvas changed size since `G3D_Init`, if another pass is begun, or if the canvas is not the bound framebuffer.
2. `G3D_Draw(*Model, @Camera)` for each model.
3. `G3D_End()` - puts the saved state back, so 2D drawing carries on as before (over the 3D picture, which the 2D calls do not depth-test).

`G3D_Shutdown(@Pass)` takes the depth buffer off the canvas and frees the shader, before the context goes. To change the canvas's size, shut the pass down and set it up again.

## The camera and the model's place

Matrices (`G3DMatrix`) are 16 floats in column-major order, as OpenGL reads them.

`G3D_LookAt(@Camera, X, Y, Z, TX, TY, TZ, Aspect, Fov, Near, Far, UpX, UpY, UpZ)` puts the camera's eye at `X, Y, Z` looking at `TX, TY, TZ`: `Aspect` is the canvas's width over its height, `Fov` the full vertical field of view in radians (0.85, about 49 degrees, by default), `Near` and `Far` the clipping distances (0.05 and 150), and the up direction `0, 1, 0` by default. It fills the camera's `viewProjection` and `eye`, and returns `#False` (changing nothing) for an impossible camera: an eye on its target, a zero or negative aspect or near distance, a far distance not beyond the near, a field of view not between 0 and pi, or an up direction along the line of sight. Distances are in the scene's own units.

Every model has a `transform` matrix, identity when it is made, which places the whole model in the scene. `G3D_Transform(@*Model\transform, X, Y, Z, Yaw, Scale)` sets it to a position, a turn of `Yaw` radians about the vertical axis and a uniform scale; `G3D_Identity` sets a matrix to identity. A program may also write the 16 values itself.

## Triangles from the program

`G3D_Mesh(*Vertices, Count, @Material, *Model)` uploads `Count` vertices, three a triangle, each six floats: its position x, y, z, then its normal. With `*Model` 0 it makes a new model; given a model it made before (in the same context), it replaces that model's triangles, reusing its buffers. Triangles are front-facing when their corners run counter-clockwise seen from outside. The vertices are copied: the program may free its memory afterwards.

A **material** (`G3DMaterial`) is a base colour (`color`, four floats), a glow added on top (`emission`, three), how metallic it is (`metal`, 0 to 1) and how rough (`rough`, 0 to 1), and whether both faces of a triangle are drawn (`twoSided`; otherwise back faces are skipped).

## Models from files

`G3D_Load(Path)` reads a glTF 2.0 binary file (`.glb`) and returns a model, or 0 with the reason in `G3D_Error()`. What it reads is a deliberate subset of glTF:

- one embedded buffer; no external files, no sparse accessors, no compressed meshes;
- triangles with float positions and normals, indexed or not; up to four joint influences a vertex;
- nodes placed by translation, rotation and scale, or by a matrix; skins with inverse bind matrices;
- materials by their factors only: base colour, metallic, roughness, emissive (with the `KHR_materials_emissive_strength` extension); textures, transparency and morph targets are refused;
- animation clips of translation, rotation and scale, linear, step or cubic-spline.

Only the nodes of the file's default scene are drawn. The full list of what is checked is in appendix A. A file that breaks one of these rules is refused as a whole, with a sentence that says which rule.

## Animation and springs

A loaded model holds its file's animation clips by name (a clip with no name is called `clip-0`, `clip-1` ...). `G3D_Play(*Model, Clip, Blend)` starts a clip from its beginning, crossfading from the present pose over `Blend` seconds (0.2 by default; 0 cuts). `G3D_Update(*Model, Seconds)` moves the clip on by that much time (at most 0.1 s a call; clips loop), recomputes every node's place, and moves the spring bones. Call it once a frame with the frame's time, before `G3D_Draw`.

A **spring bone** lags behind its parent's movement and swings back, under gravity: `G3D_Spring(*Model, Bone, Stiffness, Damping, Gravity)` makes the node named `Bone` one (stiffness 1 to 1000, 60 by default; damping 0 to 100, 12; gravity -100 to 100, 1.1 downwards). `G3D_Impulse(*Model, X, Y, Z)` adds a velocity to every spring bone of the model, in scene units a second. `G3D_Load` makes spring bones by itself of the nodes whose names start (in any case) with `breast.`, `glute.`, `bust.` or `hip.`.

The skinning is done in the vertex shader; the joints' matrices go to the GPU as a small texture once a draw.

## Shading

The shader lights every model the same way: one directional light from the direction (-0.55, 0.8, 0.55) of the scene, and reflections of a fixed studio surround defined in the shader (a sky gradient and three bright patches), mixed by the material's metal and roughness, plus its emission; the result is tone-mapped and gamma-corrected, and opaque. There is no way to add lights, shadows or textures.

A program can bend the geometry itself: GLSL source passed as the second argument of `G3D_Init` defines `void projectVertex(inout vec3 point, inout vec3 normal)`, which the vertex shader calls for every vertex before the model's matrix, and `G3D_SetProjection(@Pass, X, Y, Z, W)` sets the four numbers it can read as `projectionParams` (between `G3D_Begin` and `G3D_End`).

## Freeing

`G3D_Free(*Model)` frees a model's buffers, with its context current (a call from another context is refused and frees nothing).
